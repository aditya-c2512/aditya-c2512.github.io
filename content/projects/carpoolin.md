## Overview

CarPoolIn is an iOS application developed in Swift as an end-semester project. It explores a ride-sharing workflow that helps travellers find and coordinate shared journeys.

## What I built

- A native iOS application that supports the core carpooling and ride-sharing flow.
- Interfaces and supporting application logic for reducing coordination friction between people travelling similar routes.
