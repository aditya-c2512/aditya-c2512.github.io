# Portfolio GitHub Page

This portfolio website intends to showcase all my technical and non-technical experience, projects, and publications. The website is divided into multiple pages (as described in the "Navigation" section below) for various aspects of my portfolio.
## Navigation
### About Me 
- This is a brief overview of myself, along with current position/role (MSc Student at The University of Edinburgh).

### Experience
- This displays a list of all my Work Experience in a card layout.
- The information for each card is fetched from "experience.json" which contains an array of experiences in JSON format. 
- Each card shows some basic information about my work experience, such as Title, Company/Insitution, Start - End, and one line from the description (like a preview with "..." at the end).  

### Projects
- This displays a list of all my projects in a card layout.
- The information for each card is fetched from "projects.json" which contains an array of projects in JSON format. 
- Each card shows some basic information about my technical projects, such as Title, One Line Description, Start - End, and GitHub/Showcase Links.  

### Showcase
- This is a carousel of images and embedded YouTube videos showcasing some of the output from my projects.

### Contact Me
- This navigates back to the bottom of the "About Me" page where my contact details (email, linkedin, github, substack, etc.) are listed.
