Optimising Network Packet Processing on Low-Power ARM Single-Board Computers

Extended native XDP support for Raspberry Pi 5 networking and evaluated DPDK-over-AF_XDP against conventional socket paths.

  • C
  • Linux
  • XDP
  • AF_XDP
  • DPDK
  • Raspberry Pi 5
  • Added native XDP and AF_XDP support to the Cadence GEM network driver.
  • Reduced median RTT by 9.41% against TCP and 6.74% against UDP.
  • Measured 24.1% lower TX cost than TCP and about 52% lower RX cost than both baselines.
